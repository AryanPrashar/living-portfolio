# Living Portfolio Build Journal

### **Day 1: The Blueprint**

#### The Core Idea
The idea for **"The Living Portfolio"** is an interface that adapts and progressively learns how a visitor wants to experience the work without ever obstructing the core navigation or important points. 

#### The Wireframe Layout
Before touching any code, I created a full fledged website layout establishing the visual hierarchy and boundaries (ensuring I can visualize the product, prior to begin the coding process):
1. **Header and Top Bar**: The name box paired with the tactile **"Live Mode Switch"** gives the user a immediate sense to the adaptive features of the project which is used in combination with the central section redirects and direct links to showcase my work and personality
2. **Hero Section**:  A side-by-side split pairing an **Interactive Generative Portrait** on the left with an editorial bio, repo link, and immediate "Say Hi"/"Resume"/"Projects" buttons
3. **Experience Carousel**: A vertical carousel pairing role preview imagery with job titles, descriptions, and an orange-indicator vertical rail track
4. **Software Showcase**: Dual-level hierarchy featuring a featured horizontal carouse alongside dynamic project cards with dedicated architecture deep-dives and live sandbox triggers
5. **Hardware Gallery**: A structured grid built for physical builds 
6. **Arts and Creative Code**: A layout built around **3 invisible dividers** engineered to auto-distribute and resize dynamically across desktop, tablet, and mobile with zero layout shift.
7. **Persistent Adaptive HUD (bottom right)**: A floating **Reset button** (top orange circle) to restore neutral defaults at any time and a expandable **Pencil Button** that slides out horizontally for natural-language customization requests (ex. *"Make this feel like a futuristic design lab, but show me the programming side"*)
